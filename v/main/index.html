arXiv:2606.30566

Retrieval Observability Bounds on Provenance Detection for Agent Memory Poisoning: Measured Coverage and a Falsified Standalone Detector

Whether memory access produces a logged tool call is the single architectural variable deciding if any trajectory-based detector can see a poisoning attack. Detector reaches AUC 0.99 in-design but is falsified for standalone deployment by its own preregistered benign study (24.7–57.6% benign false positives).

arXiv:2608.28502

Instruction Self-Arbitration Is Not a Trust Boundary: Configuration-Dependent Tool Calls and External Enforcement in LLM Agents

Labels inside a shared context are not an enforceable trust boundary. The v1 keyword “detection” flag mostly matched negated phrases, and the measured execution rate depends on the scoring rule (1.21% fixed before collection, 12.9% path-based, 20.2% any delete call). An external signed-capability gate rejected every forged, tampered, replayed and unsigned record in a sandbox test; semantic authorisation remains open.

29 endpoints · 14,294 diverse-prompt trials · mechanistic probing · external enforcement (sandbox test)
